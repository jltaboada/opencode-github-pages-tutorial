# OpenCode + FreeLLMAPI + GitHub Pages Tutorial

Tutorial paso a paso para instalar OpenCode, configurar FreeLLMAPI con modelos gratuitos y publicar una web en GitHub Pages.

**Live demo:** https://jltaboada.github.io/opencode-github-pages-tutorial/

## Contenido

- Paso 1: Crear cuenta GitHub
- Paso 2: Instalar OpenCode
- Paso 3: Configurar FreeLLMAPI
- Paso 4: Conectar OpenCode a FreeLLMAPI
- Paso 5: Crear primer proyecto
- Paso 6: Subir a GitHub
- Paso 7: Publicar en GitHub Pages

Desarrollado con **frontend-design**, **web-typography** y **color-systems** skills de OpenCode.
