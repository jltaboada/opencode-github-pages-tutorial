Tutorial paso a paso: crea web con OpenCode + modelos gratuitos

Instala OpenCode, conecta FreeLLMAPI, usa GitHub para tu repo y publica en GitHub Pages. Sin coste, 100% local y sin Dreamweaver.

Objetivo: En 7 pasos tendrás un entorno de desarrollo moderno con IA gratuita y una web publicada.

⚠️ Todo lo que hagas queda en tu máquina y en tu repo GitHub. FreeLLMAPI es un agregador de modelos de código abierto.

Paso 1

Crear cuenta en GitHub

Necesitas un repositorio para almacenar el proyecto y publicar en GitHub Pages.

  1. Ve a github.com y crea una cuenta.
  2. Verifica el correo.
  3. New Repository → nombre: opencode-web → Public → Add a README → Create.
Consejo: usa un nombre de usuario legible, será la URL de tu web: https://TU-USUARIO.github.io/opencode-web/
Paso 2

Instalar OpenCode

OpenCode es el CLI/TUI que usaremos para trabajar con IA desde la terminal.

Windows / PowerShell:

winget install opencode.opencode

Mac:

brew install opencode

Verifica:

opencode --version
Primera vez: opencode login o configura un proveedor. Nosotros usaremos FreeLLMAPI como proveedor.
Paso 3

Configurar FreeLLMAPI

FreeLLMAPI agrega modelos de código abierto y gratuitos (Gemma, Mistral, Llama, etc.).

  1. Crea una cuenta en FreeLLMAPI (o similar servicio gratuito que soporte OpenAI-compatible API).
  2. Copia tu API_KEY.
  3. Anota la Base URL, típicamente: https://api.freellmapi.com/v1 (verifica en tu dashboard).
Los modelos gratuitos tienen límites de tasa. Para desarrollo y tutorial es suficiente. Guarda la key en un gestor de contraseñas.
Paso 4

Conectar OpenCode a FreeLLMAPI

Configura un proveedor personalizado en OpenCode.

Windows PowerShell:

opencode config set providers.freellmapi.baseUrl "https://api.freellmapi.com/v1"
opencode config set providers.freellmapi.apiKey "TU_API_KEY_AQUÍ"
opencode config set model "freellmapi/gemma-2-9b-it"  # ejemplo de modelo gratuito

Alternativa: edita ~/.config/opencode/opencode.json directamente.

Si usas otro proveedor, cambia baseUrl y el model. Prueba con opencode chat "hola".
Paso 5

Crear primer proyecto

Usa skills de diseño para generar web con IA guiada.

Abre la carpeta del proyecto:

cd D:\tutorial-web
opencode worktree create opencode-web

Genera con prompt guiado por skill:

Use frontend-design to scaffold a simple HTML/CSS/JS site with index.html, style.css, script.js.
Create a hero, features, and footer. Mobile-first, semantic HTML, accessible.

Skills recomendadas

  • frontend-design
  • web-typography
  • color-systems

Buenas prácticas

  • Mobile-first
  • Tokens CSS con :root
  • No usar <table> para layout
Paso 6

Subir a GitHub

Inicializa git y envía los cambios.

git init
git remote add origin https://github.com/TU-USUARIO/opencode-web.git
git add .
git commit -m "Initial commit: tutorial layout"
git branch -M main
git push -u origin main
En Windows puedes usar GitHub Desktop si prefieres GUI. El resultado es el mismo.
Paso 7

Publicar en GitHub Pages

Activa Pages en el repo.

  1. GitHub → repositorio → Settings → Pages.
  2. Source: Deploy from a branch → Branch main → Folder / (root).
  3. Save. Espera 1-2 minutos.
  4. Tu web estará en: https://TU-USUARIO.github.io/opencode-web/
Si cambias index.html, comitea y haz push. GitHub Pages se actualiza automáticamente.
